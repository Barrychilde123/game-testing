## 2. 测试覆盖

### 2.1 功能与规则

- 新开游戏生成 2 个方块，分数 0；
- 新游戏重置棋盘/分数，保留最高分；
- 左、右、上、下四个方向移动与合并；
- 2+2=4、2+2+2+2=8 的合并与计分；
- 无法移动时不生成新方块；
- 棋盘填满且无合并时游戏结束；
- 合成 2048 弹出胜利提示，可继续游戏；
- 最高分 localStorage 持久化；
- 方向键、WASD 键盘操作。

### 2.2 边界与异常

- 高数值方块 16384 的配色与可读性；
- localStorage 不可用时页面仍可运行；
- 连续 200 次方向操作稳定性；
- 320px / 375px / 1200px 视口无横向溢出；
- 3G 弱网（300ms / 500KB/s）加载与可玩性。

## 4. 性能与弱网数据

| 场景 | 结果 | 说明 |
|---|---:|---|
| 正常加载 | navigation.loadEventEnd 约 **69 ms** | 本地静态服务，Edge headless |
| 3G 弱网加载 | loadEventEnd 约 **697 ms**，实际等待约 **711 ms** | CDP：300ms 延迟、500KB/s |
| 连续 200 次操作 | 约 **2.3 ms** | 通过 JS 测试钩子循环调用 move |
| 移动端 375px | 无横向溢出 | scrollWidth ≤ innerWidth |
| 移动端 320px | 无横向溢出 | scrollWidth ≤ innerWidth |

**分析：**
- 游戏资源体积很小（HTML/CSS/JS 均为本地静态文件），正常加载在 70ms 以内；
- 3G 弱网下主要耗时是 300ms 延迟 × 3 个资源请求，加载仍在 1s 内；
- 合并算法复杂度低，200 次操作仅约 2ms，未发现性能瓶颈；
- 真实线上环境还需考虑 CDN、图片/音效资源、低端机型与真机差异。

## 6. 风险与限制

- 仅覆盖 Microsoft Edge 桌面/移动视口，未覆盖 Chrome/Safari/Firefox/真机；
- 最高分仅本地存储，清缓存/换浏览器会丢失；
- 弱网为 CDP 模拟，与真实弱网存在差异；
- 游戏无后端，未覆盖账号、排行榜、支付等场景；
- 无音效、动画、撤销等体验功能，不属于本靶场范围。
